# Run the QSPI YAML regression

From `~/workspace/Project/IPTrial_V0/dv/qspi`, use:

```bash
# Compile current sources and run the directed Micron flash smoke.
python3 regr/run_yaml_regression.py --vectors regr/vectors/smoke.yaml

# Build and run the directed Verilator XIP matrix without a solver.
python3 regr/run_yaml_regression.py --vectors regr/vectors/xip.yaml

# Validate the complete plan and print commands without compiling or simulating.
python3 regr/run_yaml_regression.py --vectors regr/vectors/full.yaml --dry-run

# Compile both configurations and run every case at seeds 1, 7, and 42.
# Requires a working SMT solver for the split constrained-random UVM sequences.
export VERILATOR_SOLVER='z3 -in -smt2'
python3 regr/run_yaml_regression.py --vectors regr/vectors/full.yaml

# Override all YAML seeds, for example for a shorter single-seed regression.
python3 regr/run_yaml_regression.py --vectors regr/vectors/full.yaml --seeds 1
```

Prerequisites: Python 3 with PyYAML, Verilator on PATH, a C++ build toolchain,
and the existing UVM/arun workspace referenced by the simulator configurations.
The script defaults to `/home/hungle/workspace/AlterDV/Common/script/arun.py`;
use `--arun /path/to/arun.py` to override it. Simulator YAML files contain workspace
paths and must be updated if the workspace is relocated.

Both supplied vectors use the adapted Micron `connect/flash/n25q256a/N25Qxxx.v`
model through `qspi_testplan.yaml`. The timeout profile uses
`qspi_testplan_timeout.yaml` with `AHB_TIMEOUT_CYCLES=16`.

## Vector fields

Vectors select UVM scenarios and simulator seeds. Transfer addresses, data,
lengths and timing remain generated by the sequences' existing constraints.
Verilator XIP uses a deterministic legal size/lane matrix without an SMT solver.
Other split tests retain constrained randomization and require a solver.
The reference `indirect_smoke` retains its existing directed behavior.

```yaml
version: 1
seeds: [1, 7, 42]
common:
  plusargs:
    - +UVM_VERBOSITY=UVM_LOW
    - +UVM_MAX_QUIT_COUNT=0
    - +QSPI_WATCHDOG_US=100000
  options:
    timeout_seconds: 240
    compile: [--assert, --coverage-user]
profiles:
  normal:
    config: qspi_testplan.yaml
  timeout:
    config: qspi_testplan_timeout.yaml
tests:
  - case: indirect
    profile: normal
    seeds: [7]  # Optional per-case override; CLI --seeds overrides all entries.
  - case: timeout
    profile: timeout
```

`common.plusargs` supplies shared runtime plusargs to every test and seed.
An explicit list replaces the runner's shared defaults, so retain the watchdog
and quit-count settings when desired. The runner adds the selected UVM test,
sequence, seed and per-run coverage path separately; these are not overridden
through common plusargs. `common.options.compile` adds argument tokens to every
Verilator build command (for example `--trace`); use YAML list entries rather
than a shell command string. `common.options.timeout_seconds` sets the wall-clock
limit per simulation. Values are recorded in the combined summary.

Configuration paths are relative to `dv/qspi`. Missing `profile` means `normal`.
The available case names are `registers`, `clocks`, `indirect_smoke`, `indirect`,
`frames`, `fifo`, `polling`, `xip`, `sioo`, `delays`, `mixed`, `irq`, `abort`, `dma`,
and `timeout`. Factory test/sequence names come from `test_map.json` and
`sequence_map.json`; callers do not need to duplicate them in YAML.

The script builds each selected profile once without running a test during
compilation, then runs isolated case/seed directories. All planned simulations
continue after a test failure. A compile/setup failure stops execution with a
nonzero exit code. Simulation failure, timeout, missing completion summary,
UVM error/fatal or checker failure makes the overall regression fail.
Warnings remain warnings. Known DDR/abort failures are not converted to passes.

## Outputs and binary reuse

Default output is `~/workspace/SIM/qspi_testplan/yaml_regression/<vector-name>/`.
Use `--out /absolute/path` to select a different directory. Outputs include:

- `build_<profile>.log`: compiler output.
- `<profile>/seed_<N>/<case>/run.log` and `coverage.dat`.
- `<profile>/seed_<N>/results.json` and `REPORT.md` from the existing result checker.
- `summary.json`: overall result and all case results, seeds and binary hashes.

An explicit reuse option is available:

```bash
python3 regr/run_yaml_regression.py \
  --vectors regr/vectors/smoke.yaml --no-build \
  --binary normal=/absolute/path/to/obj_dir/Vtop
```

`--no-build` does not verify source freshness. Without a binary override it reuses
the build path obtained from the selected simulator configuration. Default runs
always invoke the compiler. `summary.json` records whether binaries were reused.

The full vector contains 15 cases × 3 seeds = 45 simulations across two builds.
An SMT solver must pass preflight before any full-regression compilation starts.
The coverage-collector diagnostic is separate from DUT simulation and is not
counted as a testplan case.
